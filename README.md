# Python Exercises 🐍

A collection of Python exercises and projects, from beginner to advanced levels.

This repository contains my journey learning Python — starting with basic concepts and gradually moving to Object-Oriented Programming (OOP), inheritance, and real-world mini projects.

---

## 📚 Topics Covered

- **Basics** — printing, variables, conditionals, loops
- **Functions & Modules** — defining functions, imports, `if __name__ == "__main__"`
- **Data Structures** — lists, dictionaries, tuples, sets
- **File & String Handling** — formatting, f-strings
- **Object-Oriented Programming (OOP)** — classes, methods, `__init__`, `__repr__`
- **Inheritance** — parent and child classes, multi-level inheritance
- **Mini Projects** — parking system, contact manager, inquiry system, and more

## 🚀 How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/NazaninMontazeri/python_exercises.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd python_exercises
   ```

3. **Run any exercise**
   ```bash
   python practice_001/hello_github.py
   ```

4. **For OOP and project folders**, navigate inside and run `main.py`:
   ```bash
   cd practice_013
   python main.py
   ```
